# れ・こんきすた。 世界観

## 文書の方針

会話で確定した設定のみを記載し、今後の会話に基づいて更新する。未指定の設定や物語は追加しない。

## 確定している設定

- 主人公たちは異世界に降り立つ。
- 主人公たちはその世界で勢力を広げていく。
- ゲーム開始時にマップ中央へ3人のポーン（登場人物）を配置する。
- 勢力区分は「プレイヤー」「敵１」「野生」。主人公たちはプレイヤー勢力に属する。
- プレイヤーと敵１は相互に敵対する。野生は自動攻撃の対象になる敵対勢力ではない。
- 野生の鹿は攻撃されると攻撃者から離れる方向へ逃げる。
- 野生の鹿が生息し、周辺を彷徨いながら野苺を食べ、マップ内外を出入りする。
- 木と野苺は自然に生え、時間とともに成長する。
- 野生の狼が生息し、空腹時は鹿を捕食する。鹿が利用できない場合はプレイヤー勢力の人間も捕食対象になる。
- 人間は通常の食料がない場合、死体を直接捕食して生き延びることができる。

## 未決定事項

- 異世界の名称、地理、歴史、文化。
- 主人公たちの人物像、出自。
- 異世界に降り立った理由と経緯。
- 各勢力の詳しい設定、住民、その他の種族。
- 技術水準と魔法の有無。
- 勢力を広げる目的。

これらは検討事項であり、確定した世界観ではない。
