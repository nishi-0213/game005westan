## ゲーム概要

- タイトル：れ・こんきすた。
- ジャンル：コロニーシミュレーション。
- 参考作品：RimWorld（リムワールド）。
- プレイヤーは異世界に降り立った主人公たちを操作し、勢力を広げていく。

## 開発技術

- PixiJS
- TypeScript
- HTML / CSS

PixiJS 8.14.3、TypeScript 5.9.3、Vite 7.1.12 を使用する。

## 今回の実装範囲

- 四角形のマスからなる32×32マスのマップ。
- マップ中央の隣接するマスに3人のポーンを配置する。
- ゲーム画面はブラウザウィンドウ全体を使用する。
- 初期表示はマップ全体が表示されるように、ウィンドウサイズに合わせる。
- HTML/CSS要素は最小限とし、ゲームは PixiJS の canvas に描画する。
- ゲーム全体で右クリックの標準メニューを無効にする。

## ポーンの選択と移動

- 左クリックでポーンを選択する。選択中のポーンには輪を表示する。
- ポーン以外を左クリックすると選択を解除する。
- 選択中にマップ内のマスを右クリックすると移動先を指定する。
- ポーンの位置と待機座標は整数のマス座標で管理する。
- マス間は滑らかに補間して描画し、マスの中心を順に通る。
- 上下左右と斜めの8方向の隣接マスへ移動できる。両軸に差がある間は斜めに進む。
- 移動速度は毎秒4マス分の距離。斜めの1区間は長さが√2マスなので、上下左右の1区間より√2倍の時間をかける。
- 移動中に移動先を変更した場合、現在移動している区間の終点まで進んでから新しい移動先へ向かう。
- マップ外への移動指示は受け付けない。

コロニー運営の仕組みは未実装。

## カメラ操作

- W/A/S/Dキーでカメラを上/左/下/右へ移動する。同時押しで斜めにも移動できる。
- カメラ移動速度は画面上で毎秒400ピクセル。斜め操作でも速度を一定にする。
- マウスホイールを上へ回すとズームイン、下へ回すとズームアウトする。
- マウスカーソルの位置を基準にズームする。倍率は初期表示の0.5〜4倍。
- カメラ移動・ズーム後も左クリックでの選択と右クリックでの移動指示が可能。
- ウィンドウサイズ変更時はカメラ位置と倍率を保持する。

## 建設タブ

- 画面左下に「建設」タブを表示する。
- 左端と下端に余白なく接し、カメラ移動・ズーム時も画面上の位置を固定する。
- 今回はタブの表示を実装する。建設メニューの内容や建設操作は未指定。

## 開発とビルド

- 依存関係の導入：`npm ci`
- 開発サーバー：`npm run dev`
- 型チェックと本番用ビルド：`npm run build`
- マス移動の検証：`npm test`

## 公開先

GitHub Pages を使用してゲームを公開する。

`main` への push を契機に GitHub Actions でビルドし、GitHub Pages に配置する設定を用意する。リポジトリの Settings → Pages → Source で GitHub Actions を選択する必要がある。公開完了は未確認。
