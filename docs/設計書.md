# れ・こんきすた。 設計書

## 文書の方針

会話で確定した内容を記載する。未確定の仕様は実装せず、今後の会話に基づいて更新する。指示されていないコーディングは行わない。

## ゲーム概要

- タイトル：れ・こんきすた。
- ジャンル：コロニーシミュレーション。
- 参考作品：RimWorld（リムワールド）。
- プレイヤーは異世界に降り立った主人公たちを操作し、勢力を広げていく。

## 開発技術

- PixiJS
- TypeScript
- HTML / CSS

PixiJS 8.14.3、TypeScript 5.9.3、Vite 7.1.12 を使用する。

## 今回の実装範囲

- 四角形のマスからなる32×32マスのマップ。
- マップ中央の隣接するマスに3人のポーンを配置する。
- ゲーム画面はブラウザウィンドウ全体を使用する。
- 初期表示はマップ全体が表示されるように、ウィンドウサイズに合わせる。
- HTML/CSS要素は最小限とし、ゲームは PixiJS の canvas に描画する。
- ゲーム全体で右クリックの標準メニューを無効にする。

## ポーンの選択と移動

- 左クリックで対象を選択する。通常のクリックは既存の選択を置き換え、空白のクリックは選択を解除する。選択中の全ポーンには輪を表示する。
- 左ドラッグで選択枠を描画し、枠内に中心が入る複数のポーンを選択する。人間と鹿が対象となる。建設予定地の配置中は従来どおり建設のドラッグ操作を優先する。
- Shift＋左クリックでポーン・アイテム・環境オブジェクトを追加選択する。異なる種類を混在して選択でき、既に選択した対象への追加クリックでは解除しない。Shift＋空白クリックは選択を保持する。
- Shift＋ドラッグは枠内のポーンを追加選択する。上部のポーンボタンもShift＋クリックに対応する。ズーム・カメラ移動後も画面上の選択枠に合わせて判定する。
- アイテム・環境オブジェクトのダブルクリックによる10×10マスの同種選択を維持し、Shift併用時は既存の選択に追加する。ドラッグ中の右クリック・操作キャンセル・フォーカス喪失では確定前の選択を保持する。
- 選択中の徴兵された生存プレイヤーポーンに対して、右クリックで移動先を指定する。複数の場合はクリック位置とその周辺の到達可能な別々のマスに割り当てる。自動状態・死亡・野生のポーンには手動の移動指示を出さない。
- 全てのポーンは、勢力・種類を問わず他のポーンがいるマスを通過できるが、同じマスに停止できない。他のポーンの現在位置・通過中の区間・予約済み移動先は、新たな停止先に指定できない。ポーンがいるマスへの右クリック移動指示は無効とする。
- 建設・収集・運搬・食事・自由行動・鹿の退出でも停止先を予約し、重複を避ける。作業を中断したときも他のポーンを通過し終えた停止可能なマスまで進む。地形の経路探索キャッシュを共有し、ポーンの占有は停止候補にだけ適用する。
- 他のポーンを通過中に死亡した場合は、最寄りの到達可能な空きマスへ死亡位置を確定し、死亡したポーンも停止位置の重複を防ぐ。
- 徴兵モードで移動指示を出すと、ポーンの現在位置から残りの経路のマス中心を結ぶ白線を表示する。複数指示では各ポーンの経路を表示し、到着・死亡・自動への切替・攻撃や装備等の別命令で消す。経路の再探索にも追従する。
- 移動指示時に、移動先のマス中央へマスと同じ大きさの○を表示する。
- ○はマスと重ね、マップとポーンより手前に白線と暗い縁取りで描画する。
- ○は0.5秒間表示した後、0.25秒かけてフェードアウトする。カメラ移動・ズームに追従する。
- ポーンの位置と待機座標は整数のマス座標で管理する。
- マス間は滑らかに補間して描画し、マスの中心を順に通る。
- 上下左右と斜めの8方向の隣接マスへ移動できる。徴兵の移動指示・自動作業・自由行動は全て最短通行経路を探索し、そのマス中心列に沿って移動する。
- 壁を避け、斜めでも壁の角をすり抜けない。経路の途中に新たな障害物ができた場合は元の目標へ再探索する。到達不能な移動指示は受け付けない。
- 移動速度は毎秒4マス分の距離。斜めの1区間は長さが√2マスなので、上下左右の1区間より√2倍の時間をかける。
- 移動中に移動先を変更した場合、現在移動している区間の終点まで進んでから新しい移動先へ向かう。
- マップ外への移動指示は受け付けない。

コロニー運営の仕組みは未実装。

## ポーンの状態

- 画面右下に、選択中のポーンの状態ボタンを固定表示する。アイコンの下に「徴兵」または「自動」を表示し、複数選択で状態が異なる場合は「混在」とする。
- ボタンを押すと、選択した生存プレイヤーポーンの徴兵・自動を一括で切り替える。全員が徴兵なら自動へ、それ以外は徴兵へ統一する。状態はポーンごとに保持する。
- 初期状態は徴兵とし、従来の右クリックによる移動指示を受け付ける。
- 自動モードでは右クリックによる移動指示を受け付けず、素材の取得・運搬と建設を自動で行う。作業がない、素材が足りない、到達できない場合は待機する。
- 移動中に自動へ切り替えた場合は、次の停止可能なマスの中心で停止する。バリケード通過中は安全なマスまで抜けてから停止する。
- ポーン未選択時はボタンを無効化する。建設予定地の配置モードを選ぶとポーンの選択も解除する。
- ポーン選択中は徴兵ボタンの左隣に「地面に置く」ボタンを表示する。所持品も装備武器もなければ無効化する。
- 地面に置く操作は、選択した生存プレイヤーポーンのうち所持品または装備武器がある全員が対象となる。現在の作業を解除し、停止可能なマスまで進んでから、そのマスへ所持品の全量と装備武器を置く。武器を置いた後は素手となる。同素材の山があれば合算する。自動モードは維持するため、その後の作業で再取得する場合がある。
- 複数選択時の左下スペックは、最後にクリックした人間（範囲選択時は選択された先頭の人間）を表示する。「今すぐ食べる」もこの人間を対象とする。アイテム・環境オブジェクト・鹿の情報は、最後に選んだ対象を表示する。
- 種類が混在した選択では、徴兵・所持品を置く・取得・収集・情報のボタンを重ならずに並べる。取得と収集の切り替えは、それぞれ選択中の全アイテム・全環境オブジェクトに適用する。
- ポーン選択中は左下の建築バーの上にスペックウィンドウを表示し、現在の行動を示す。建築の下位メニューが開いている場合はその上へ配置し、選択解除時は非表示にする。
- 行動表示は「自由」「建築中」「収集中」「徴兵」「素材を取得中」「素材を運搬中」「素材を搬入中」「収集へ移動中」「建設へ移動中」「地面に置く」「アイテムを取得中」「保管箱へ運搬中」「待機」とする。
- 画面上中央にポーンボタンを左から右へ並べる。各ボタンはポーンの拡大イメージと、その下にあだな（なければ名）を表示する。ボタンの枠は正方形とし、ボタン間に少し隙間を設ける。
- ポーンボタンのクリックで選択し、ダブルクリックで選択とカメラの中央への移動を行う。カメラはそのポーンの現在の描画位置に合わせ、ズーム倍率は保持する。

## カメラ操作

- W/A/S/Dキーでカメラを上/左/下/右へ移動する。同時押しで斜めにも移動できる。
- カメラ移動速度は画面上で毎秒400ピクセル。斜め操作でも速度を一定にする。
- マウスホイールを上へ回すとズームイン、下へ回すとズームアウトする。
- マウスカーソルの位置を基準にズームする。倍率は初期表示の0.5〜4倍。
- カメラ移動・ズーム後も左クリックでの選択と右クリックでの移動指示が可能。
- ウィンドウサイズ変更時はカメラ位置と倍率を保持する。

## ポーン名と作業優先順位

- 姓・名・あだなの候補を `src/data/pawn-name-pool.ts` に用意し、ゲーム開始時にそれぞれの候補からランダムに名前を生成する。3人の間で各候補の重複を避ける。
- 名前候補は日本風に加え、欧州・米州・アジア・アフリカなどの姓・名と英語のあだなを多数含める。
- 「建設」の右隣に「優先順位」タブを表示する。押すとポーン一覧と「建設」「収集」「運搬」「解体」「自由」の数値を並べたウィンドウを開閉する。
- 一覧の名前は「姓 名『あだな』」の形式とする。
- 初期値は全ポーンの建設・収集・運搬・解体・自由ともに3。
- 数値をクリックすると1→2→3→4→1…の順に切り替える。小さい数値ほど優先する。
- 優先順位はポーンごとに保持し、自動モードの実際の作業選択へ反映する。
- 実行できる仕事が複数ある場合は優先順位で選び、同値なら収集、運搬、建設、解体、自由の順に優先する。高優先の仕事がない、または到達不能な場合は他の仕事を行う。
- 優先順位変更で現在の作業より高い仕事があれば中断して切り替える。建設・収集の保存済み進捗は保持する。
- 自由が選ばれた自動ポーンは、5秒ごとに周囲±3マスから到達可能な別のマスをランダムに選び、移動する。壁を避け、完成したバリケードには停止しない。徴兵中には自由行動を行わない。

## 建設タブ

- 画面左下に「建設」タブを表示する。
- 左端と下端に余白なく接し、カメラ移動・ズーム時も画面上の位置を固定する。
- 「建設」を押すと、その上に「建物」「作業所」「防衛」の下位タブを横並びで表示する。
- 「建設」を再度押すと下位タブを閉じる。
- 「建物」を押すと「壁」を選択できる。
- 壁ボタンを右クリックすると「木材」「石材」の素材選択を表示する。初期素材は木材。
- 建築ボタンに「壁（木材）」「バリケード（石材）」のように現在の素材を表示する。
- 壁ボタンを選択すると壁の配置モードになる。同じボタンを再度押すと配置モードを解除する。
- 素材を選ぶと、その素材の壁を配置するモードになる。
- 建設メニューを閉じるか、別の下位タブに切り替えると配置モードを解除する。
- 壁・バリケードの配置モード中、予定地がない場所を右クリックすると配置モードを解除する。建設ボタンの右クリックは素材選択として扱う。
- 建設予定地を右クリックすると、配置モード中でも直接削除して配置モードを解除する。担当ポーンの作業を解除し、搬入済み素材はそのマスに戻す。進捗バーも削除する。完成した建築物はこの操作では削除しない。

## 壁と建設予定地

- 壁を選択し、マップを左クリックまたは左ドラッグして建設予定地を設置する。
- 建設予定地はマス単位で配置する。ドラッグ中に飛ばしたマスも補間して配置する。
- 同じマスに予定地や壁を重複して配置しない。マップ外には配置しない。
- 予定地には透過30%（不透明度70%）の壁を表示する。
- 壁はマスと同じサイズの四角形。木材は茶色、石材は灰色。
- 予定地は通行可能とし、建設完了後の壁は通行不可とする。
- 壁はポーンではなく固定の建物なので、移動指示の対象にはならない。
- 完成した壁のマスへは移動先を指定できない。移動経路に壁がある場合は手前のマスで停止し、斜め移動でも壁の角をすり抜けない。
- 建設完了時に予定地を不透明な壁へ切り替える処理を用意する。ポーンのいるマスや移動中の区間を塞ぐ完成処理は受け付けない。
- 自動モードのポーンが素材を搬入し、建設時間を満たすと不透明な完成壁へ切り替える。
- 作業所タブの内容は未指定。

## バリケードと建設予定地

- 「防衛」タブから「バリケード」を選択できる。
- ボタンの右クリックで木材・石材を選択する。初期素材は木材。素材の選択は壁と別に保持する。
- 壁と同じ建設予定地の仕組みで、左クリック・ドラッグにより配置する。予定地は透過30%（不透明度70%）。
- 木材は茶色、石材は灰色。形は壁の下半分に相当し、マスの幅全体・高さ半分の四角形をマス下半分へ描画する。
- ポーンはバリケードより手前に表示する。
- 完成したバリケードのマスは通過可能。ただし待機・停止位置や移動先には指定できない。
- バリケード自体は固定の建物なので移動指示できない。
- バリケードの先に壁があり安全に通り抜けられない場合は、バリケードへ入る手前の停止可能なマスで停止する。
- 通過中の移動先変更によってバリケード上に取り残される指示は受け付けない。
- 完成処理は壁と共通。ポーンの現在位置、移動区間、移動先やバリケードからの出口を塞ぐ完成処理は受け付けない。
- 自動モードのポーンが素材を搬入し、建設時間を満たすと完成する。

## 自動建設

1. 到達可能な建設予定地のうち、最も早く接近できる予定地を記録する。
2. その予定地に必要な素材のうち、必要資源のある保管箱・保管エリアのうち、最も早く到達できる場所を選んで移動する。地面の素材を直接建設に使わない。
3. 保管箱の隣接マス、または保管エリアのマスに到達したら取得する。ポーンは1種類の素材を最大20kgまで所持できる。木材は最大20個、石材は最大5個で、残りは保管場所に残す。
4. 素材取得後、所持素材が必要な予定地の中から再び最も早く接近できる予定地を選ぶ。
5. 予定地の隣接マスから、所持素材を1個ずつ予定地へ搬入・消費する。必要数を超えて消費しない。
6. 必要素材が全て揃った後、必要時間だけ建設し、完成状態に切り替える。

| 建築物 | 必要素材 | 建設時間 |
| --- | --- | --- |
| 壁 | 選択素材10個 | 1秒 |
| バリケード | 選択素材5個 | 1秒 |
| 保管箱 | 木材30個 | 3秒 |
| 保管エリア | 不要 | 即時（環境オブジェクトが重なる場合は収集後） |

- 到達時間は上下左右と斜めの最短通行経路の距離から判定する。斜めの距離は√2とし、壁の角をすり抜けない。
- 保管箱からは隣接マス、保管エリアからは同じマスで素材を取得する。建設は予定地の周囲8マスのうち最短で到達できる停止可能なマスから作業する。
- バリケードは経路上で通過できるが、素材取得や建設作業の停止位置にはできない。
- 同じ予定地を複数のポーンが同時に担当しないよう予約する。
- 1つの予定地に対して、同時に搬入・建設するポーンは1人だけ。予約の所有者だけが作業を進め、中断後は他のポーンへ引き継げる。
- 1回の運搬で必要素材が揃わない場合は、取得と搬入を繰り返す。石材の壁は5個ずつ複数回運搬する。
- 素材不足時は搬入済みの数を保持し、追加の素材が用意されるまで待つ。建設時間は必要数を満たすまで進まない。
- 別の素材へ切り替える必要がある場合、所持素材を現在のマスへ戻してから次の素材を取得する。同じ素材の山があれば合算する。
- 徴兵へ切り替えた場合は担当を解除し、停止可能なマスで停止する。所持素材と搬入済み素材、建設進捗は保持する。
- 建設進捗はポーンの担当状態とは別に、建築予定地ごとの作業済み秒数として保持する。中断中は増えず、同じポーンまたは別の自動ポーンが残り時間から再開する。
- 建設中の壁・バリケードの下に、マス幅の小さな進捗バーを表示する。進捗は作業済み時間／必要建設時間で計算する。
- 0%と100%では進捗バーを表示しない。中断時は途中のバーを保持し、再開すると続きから伸びる。バーはカメラ移動・ズームに追従する。
- 完成が他のポーンの位置や移動区間を塞ぐ場合は、安全に完成できるまで待つ。

## マップ上のアイテムとアイテム欄

- マップ中央付近に木材100個と石材200個を配置する。初期座標は木材が（列16、行16）、石材が（列17、行16）。座標は0始まり。
- アイテムの種類、数量、マス座標を描画とは別に管理する。
- マップ上のアイテムは四角形のプレースホルダーで表示する。木材は茶色、石材は灰色。
- 各アイコンの下に、そのマスにあるアイテムの数量を小さく表示する。
- アイコンと数量の位置はカメラ移動・ズームに追従する。数量の文字サイズは画面上で10pxに固定し、ズームで拡大・縮小しない。
- canvasの描画解像度は少なくとも画面ピクセルの2倍、数量テキストはその2倍の解像度で生成し、文字のぼけを抑える。
- 画面左上にアイテム欄を固定し、木材、石材の順に上から下へ並べる。
- アイテム欄は「アイテムのアイコン：数量」の形式で表示する。
- 集計対象は完成した保管箱・保管エリアに保管されたアイテムだけ。地面の山は含めない。保管数0の種類は表示しない。カメラの表示範囲に左右されない。
- 保管場所から素材を取得・保管場所へ搬入すると集計を更新する。所持中・建設への搬入済み素材は集計に含めない。
- 素材を所持しているポーンの手元に小さなアイテムアイコンを表示する。木材は茶色、石材は灰色で、所持素材の変更に追従する。所持品がなくなると非表示にする。
- 質量は1個あたり木材1kg、石材4kgとする。所持上限は20kg。質量による移動速度への影響は設定しない。
- マップ上のアイテムを左クリックで選択できる。選択したアイテムのマスを枠で示す。
- アイテム選択時は右下のポーン状態ボタンの代わりに「?」（インフォメーション）ボタンを表示する。
- ?ボタンを押すとプロパティウィンドウを表示する。アイテム名を上、下に「質量　1kg」（木材）または「質量　4kg」（石材）を表示する。山全体ではなく1個あたりの質量。
- ウィンドウは閉じるボタンまたはEscapeキーで閉じる。別のアイテムを選択すると内容を更新し、選択解除や素材取得で山がなくなった場合は閉じる。

## 環境オブジェクトと収集

- マップ上の木と岩を「環境オブジェクト」と呼ぶ。中央のポーン・素材の周辺は空け、重複しないマスへ生成する。
- 木24本は滑らかな値ノイズから密度を作り、ノイズに基づく重み付き抽選で配置する。密集する場所と疎らな場所が生じる。
- 岩は4つのまとまりを生成する。各まとまりは3〜8個が直線またはジグザグに連なり、まとまり同士は接しない。
- 木は薄い緑（#8fba7a）の樹冠と茶色の幹、岩は灰色の楕円の図形で仮表示する。
- 左クリックで単独選択する。同じマスのポーンや地面アイテムが選択できる場合はそちらを優先する。
- ダブルクリックで、その対象と同種の環境オブジェクトを10×10マス内で複数選択する。対象の列・行からそれぞれ−5〜＋4の範囲を使い、マップ端では範囲外を除く。
- 選択中は右下に「無視・収集」の切り替えボタンと?ボタンを表示する。初期状態は無視。複数選択時はまとめて変更する。
- ?ボタンから、環境オブジェクト名・収集速度（所要秒数）・現在のHPに応じた収集量・HPを表示する。

| 対象 | 収集速度 | 収集量 |
| --- | --- | --- |
| 木 | 4秒 | 木材12個（HP100%時） |
| 岩 | 5秒 | 石材8個（HP100%時） |

1. 自動ポーンは、収集に指定された到達可能な対象のうち最も早く接近できるものを登録する。
2. 最短経路で、対象の周囲8マスの停止可能な隣接マスに接近する。
3. 所定時間だけ収集作業を行う。同じ対象は1人が担当する。
4. 完了した対象を消し、そのマスへ素材アイテムを生成する。同じ種類の山があれば合算する。生成物は所持品には直接入れない。

- 実行優先順位はポーンごとの設定に従う。同値の初期設定では **収集 ＞ 建設**。仕事を切り替えても保存済み進捗から再開する。
- 徴兵中は収集しない。無視への変更や徴兵で中断した収集時間は対象に保持する。
- 収集指定の環境オブジェクトの上に、金色の収集アイコンを表示する。無視へ戻すか収集完了で非表示にする。
- 収集作業の進捗バーを対象の下に表示する。所要時間に対する作業済み時間で計算し、0%・100%では表示しない。中断時は保存された進捗を表示し、再開時に続きから伸びる。
- 木・岩のマスは通過できるが、待機・停止・移動先指定はできない。徴兵の移動指示・自動建設・収集・自由行動・地面に置く操作で共通の条件を守る。収集完了後のマスは停止可能になる。
- 完成した壁やバリケードの通行・停止条件は収集時も守る。
- 建設予定地と未収集の環境オブジェクトが重なる場合、予定地の配置時にその木・岩を収集指定にする。
- 重なった予定地への素材搬入・建設・完成は、環境オブジェクトの収集が終わるまで行わない。建設の優先順位が高くても、この前提条件は守る。
- 対象を無視へ戻した場合は収集も建設も待機し、再び収集指定すると再開する。他の重なっていない予定地は通常の優先順位で作業できる。

## 取得指定と保管

- 地面のアイテムは「無視」を初期状態とする。選択時の右下のボタンで「取得・無視」を切り替える。取得指定の山には目印を表示する。
- アイテムをダブルクリックすると、その山を中心に縦横10マス（-5～+4）の同種類の山を複数選択し、まとめて指定できる。
- 自動モードのポーンは取得指定の地面アイテムを取得し、受け入れ可能で到達できる最寄りの保管場所へ運ぶ。無視の山は運ばない。
- 運搬は独立した「運搬」の優先順位を使う。取得指定の地面アイテムを保管箱・保管エリアへ運ぶ作業と、保管資源を建設予定地へ搬入する作業を含む。「建設」は必要素材が揃った予定地での建築作業のみを指す。
- 運搬時も1種類・最大20kgの所持制限を守る。同じ山の取得担当を予約し、重複取得しない。徴兵等の中断で所持品を失わない。
- 建設の下位タブに「保管」を追加し、「保管エリア」「保管箱」を選択して配置する。
- 保管エリアは資源不要で、何も重ならないマスでは即時設置する。木・岩が重なる場合は先に収集する。1マスにつき1種類だけ、最大100個を格納する。空になると別の種類も保管できる。
- 保管エリアは通過・停止可能。枠で表示し、保管資源のアイコンと数量をエリアの上に表示する。数量の文字サイズはズームに左右されない。
- 保管箱は木材30個・3秒で建造し、格納数は無制限。完成した箱は通行不可で、隣接マスから出し入れする。
- 完成した保管箱を右クリックすると設定ウィンドウを開き、木材・石材・苺の受け入れを個別に切り替える。初期状態は全種類を受け入れる。設定を無効にしても既存の中身は残り、建設用に取得できる。
- 空き容量不足・受け入れ先なし・到達不能の場合は無理に取得しない。運搬中に空きがなくなった場合も上限を超えず、残りは保持して別の場所を探す。
- 全てのインフォメーションボタンの記号を「?」に統一する。

## タブの排他表示

- 建設と優先順位は同時に開かない。別のタブを選択すると、既に開いているタブとその下位タブ・素材メニューを閉じる。
- 建設内でも、建物・作業所・防衛・保管のうち選択したタブの内容だけを表示する。現在選択中のタブを再度押すと閉じる。

- 運搬が素材を必要数まで搬入すると、予定地の担当予約を解除して建設担当へ引き継ぐ。同じポーンが続ける場合も、その時点の建設優先順位で判断する。搬入済み素材と建設進捗は中断や担当交代でも保持する。
- 地面から取得したアイテムは保管場所への運搬を完了してから、次の建設用運搬を選ぶ。運搬中に別の仕事へ切り替えても所持品を失わない。

## ポーン情報欄の内容

- ポーン選択時の左の情報欄は、上部に「姓 名『あだな』」のフルネームを大きく表示する。
- その下に現在の行動と、所持アイテムのアイコン・種類・数量を表示する。所持品がなければ「所持：なし」。
- 資源の取得・搬入・地面に置く操作に合わせて所持表示を更新する。

## 建築物の破壊

- 建設タブに「破壊」ボタンを表示する。選択中に完成した壁・保管箱を左クリックすると破壊対象に指定し、赤い×印を重ねる。
- 右クリック、別の建設ボタンやタブの選択で破壊指定モードを解除する。指定済みの対象は保持する。
- 自動ポーンが「建設」の優先順位で接近し、隣接する停止可能なマスから破壊する。同じ対象を同時に作業するポーンは1人だけ。
- 破壊時間は現状、元の建設時間と同じ（壁1秒・保管箱3秒）。中断時の作業進捗を保持して再開する。
- 破壊完了で建築物と×印を取り除き、そのマスへ建設素材の半分を返す（壁は選択素材5個、保管箱は木材15個）。
- 保管箱の中身は建材の返却とは別に全量を地面へ戻す。保管済み資源の集計からは外れ、再び取得指定して運搬できる。
- 行動表示に「破壊へ移動中」「破壊中」を追加する。

## 野苺と食料

- 野苺を環境オブジェクトとしてマップに16個ランダム配置する。木・岩や中央初期配置と重ならない。
- 野苺は木・岩と同じ選択・範囲選択・収集指定・経路探索の仕組みを使う。通過できるが停止・移動先指定はできない。
- 収集時間は1秒、HP100%時の収集量は苺5個。成長途中の収集量はHPに比例する。完了時に野苺を除去し、そのマスへ苺の地面アイテムを生成する。苺は自動で取得指定にする。
- 苺は赤い四角形のプレースホルダー、1個0.2kg。運搬・保管・数量・インフォメーションは既存アイテムと共通。20kgの上限では最大100個を運べる。

## ポーンの欲求と死亡

- ポーン情報欄に「概要」「欲求」タブを設け、一方だけを表示する。従来のフルネーム・行動・所持品は概要に表示する。
- 欲求には満腹感・健康・覚醒度を0～100%のゲージと数値で表示する。初期値はいずれも100%。
- 満腹感はゲーム内時間で毎秒1%減少する。20%以下になると、所持する苺を食べるか、到達可能な最寄りの食料へ移動する。到着後の食事時間は個数に関係なく1秒。満腹感100%までに必要な個数（1個あたり10%回復）をまとめて消費する。足りない場合は利用可能な数量だけを消費する。
- 食料は所持品、保管箱・保管エリア、取得指定の地面の苺から探す。無視の地面アイテムは取得しない。食料がなければ消費せず、満腹感は0%で下限となる。
- 食料へ移動する間は通常作業を中断し、作業予約を解除する。建設・収集・破壊の進捗と所持品は保持する。食事は徴兵・自動の両モードで行う。
- 満腹感0%の間、健康は毎秒1%減少する。0%に達した瞬間より前の時間は健康減少に含めない。食べると健康の減少は止まるが、回復は現状行わない。
- 全ポーンに健康とは別のHPを追加し、初期値は100%。人間は概要にHPを表示し、鹿のインフォメーションもHPを表示する。
- 健康0%になると、HPが0.1ゲーム秒あたり1%（毎秒10%）減少する。健康が0%に達する前の時間はHP減少に含めない。
- HP0%で死亡する。攻撃によってHPが0%になった場合も、健康値にかかわらず即座に死亡する。マップ上と上部のポーン画像は横倒しになり、概要の行動表示は「死亡」。死亡時点の描画位置を保持する。
- 死亡時は全作業の予約を解除し、移動・作業・食事を停止する。徴兵切り替え、移動指示、所持品を置く操作は無効にする。情報を見るための選択は可能。

- 生存ポーンを選択した状態で地面や保管エリア上の苺を右クリックすると、「今すぐ食べる」の操作ウィンドウを表示する。
- 明示的に食べる指示を選ぶと、満腹感や取得・無視の状態に関係なくその苺へ移動し、1秒で満腹感100%に必要な個数をまとめて消費する（1個あたり10%回復、上限100%）。通常作業は中断し、モードと所持品は維持する。死亡ポーンには食事指示できない。

- 食事時間中の行動欄は「食事中」。食料が尽きた場合は数量を負にせず、利用可能な分だけを食べる。

## ゲーム速度

- 画面右上に「一時停止」「1倍」「3倍」を表示する。初期値は1倍で、現在の速度を強調する。狭い画面では上部ポーンボタンの下に配置する。
- ポーン移動、建設、搬入、運搬、収集、破壊、自由行動、食事、満腹感・健康の時間経過を同じゲーム内時間で進める。3倍では全て3倍の速度、一時停止では進まない。
- 固定時間刻みで作業を処理し、1個ずつの素材搬入も速度に合わせて進む。
- 停止中も選択・指示・建設予定地の配置・カメラ操作は可能。指示後の移動や自動作業は再開してから進む。
- カメラの速度と移動先の○の表示時間はゲーム速度に左右されない。

## 建設予定地のアイテム整理

- 建設予定地に地面アイテムが重なる場合、自動ポーンが先に付近の置けるマスへ運び出す。取得・無視の設定に関係なく、建設に必要な整理として行う。
- 整理は「運搬」の優先順位を使い、素材搬入・建設は整理完了を待つ。アイテムを拾った後も、運び出して置くまでは予定地を整理中として保持する。
- 所持上限20kgを守り、複数の種類や大量の山は必要な回数だけ往復する。既に所持品がある場合は、安全な置き場所へ置いてから整理する。
- 置き場所は到達できる停止可能なマスから近い場所を選ぶ。建設予定地・完成建築物・環境オブジェクト・別種アイテムと重ねない。同種の山には合算できる。
- 置き場所が後から塞がれた場合は、所持品を保持して別の場所へ運ぶ。置ける場所がない場合はアイテムを取得せず、建設を待機する。
- 移動したアイテムの数量・取得指定を保持する。担当予約で複数ポーンの重複整理を防ぐ。
- 環境オブジェクトも重なる場合は、先に収集し、生成された地面アイテムも運び出してから建設する。資源不要の保管エリアにも同じ条件を適用する。

## 作業判断と経路探索の最適化

- 作業候補の再確認は0.25ゲーム秒ごと。優先順位を変更した場合、または担当作業が完了・解除された場合はすぐ再判断する。
- 優先順位が高い作業から確認し、実行可能な作業が見つかった時点で候補検索を終える。実行中の作業は保持し、自由・収集・運搬・建設それぞれで不要な下位作業の探索を省く。
- 最短経路探索の待ち行列はヒープを使う。全到達マスの経路配列は最初から生成せず、採用する経路が必要になった時に組み立てる。
- 同じ通行条件・開始マスの探索結果を共有し、最近の16開始マスまで保持する。壁・バリケード・保管箱の完成、破壊、環境オブジェクトの採取完了で更新する。
- 自由移動では周囲±3マスの候補だけを抽出し、選んだ1本の経路だけを組み立てる。環境オブジェクトの通行判定はマス座標から直接参照する。
- 建設素材や受け入れ可能な保管先が存在しない場合は、経路探索に入らない。建設候補の確認では、同じ素材の保管元一覧を再利用する。
- 予定地のアイテム退避先は近いマスの輪から順に検索し、置ける範囲が見つかれば遠方の検索を止める。
- アイテム描画を参照表で管理し、毎フレームの総当たり照合をなくす。数量ゼロのアイテム表示、採取済みの環境オブジェクト表示、完成した建設の進捗バーは解放する。
- 数量・行動・ボタン・保管設定の表示は変化があった時だけ書き換える。閉じた欲求・保管設定の表示更新を省き、ポーン情報の配置計算はメニュー表示や画面サイズの変更時だけ行う。
- 進捗バーは図形を再生成せず、塗りつぶし部分の横倍率を変更する。マップ上の入力は既存のcanvasイベントで処理し、使っていないPixiJSのシーン内ヒットテストを省く。
- 移動・作業時間・空腹などのシミュレーションは従来の固定ステップを維持し、判断処理の間引きによって移動の滑らかさや時間倍率を変えない。
- `npm run benchmark` で、同じ乱数・32×32マップ・3人の採取／自由行動を15ゲーム秒分実行し、描画を除く処理時間を測定できる。比較元のチェックアウトを指定する場合は `npm run benchmark -- /path/to/checkout`。自由行動の5秒ごとの実移動も測定に含める。

2026-10-13のクラウド環境で、変更前 `3f46842` と同一条件で測定した結果：採取は23,993ms→57ms、自由行動は34,562ms→22ms。両方とも移動中ステップ数は変更前後で一致した。この値は描画を除くシミュレーション処理時間であり、利用端末のFPSを示すものではない。

## 勢力と野生動物

- ポーンに種別と勢力を持たせる。勢力は「プレイヤー」「敵１」「野生」。既存の人間3人はプレイヤー、鹿は野生に属する。
- プレイヤー所属の人間だけが徴兵・自動の切替、移動指示、所持品の操作、食事指示を受け付ける。上部一覧と優先順位一覧もプレイヤーの人間を対象とする。
- 人間の概要に勢力を表示する。鹿はクリックで選択・情報確認できるが操作はできない。?ボタンから勢力、現在の行動、満腹感、健康、HPを確認できる。
- 鹿は図形の四足動物として表示する。人間と共通の経路探索で、5ゲーム秒ごとに周囲±3マスの停止可能なランダム位置へ移動する。
- 鹿の満腹感が20%未満になると、到達が最も早い野苺へ向かい、隣接マスで収穫してその場で食べる。人間の収集指定は不要。人間・鹿で収穫対象の占有を共有する。
- 収穫に1ゲーム秒、食事に1ゲーム秒かかる。食事は収穫した量の範囲内で満腹まで食べ、苺1個で10%回復する。収穫量が0個の幼株は食料探索の対象にしない。
- 鹿は到達可能な地面・保管場所の苺・携帯食料を食べ、利用できなければ収穫した苺をその場で確保して食べる。成長途中の株は得られた個数だけ食べる。
- 満腹感の減少は人間と同じ毎ゲーム秒1%。満腹感0では健康が毎ゲーム秒1%減少する。健康0になるとHPが0.1ゲーム秒あたり1%減少し、HP0で死亡する。死亡時は行動と移動を停止し、横倒しで表示する。
- 開始時に最初の2〜3匹がマップ端へ出現し、以後50〜70ゲーム秒のランダム間隔で2〜3匹が出現する。建築物・環境オブジェクト・ポーンがいるマスを避ける。
- 退出も独立した50〜70ゲーム秒の間隔で、生きていて退出中でない鹿からランダムに2〜3匹を選ぶ。対象が少なければ存在する匹数までとする。
- 退出フラグが立つと収穫・食事・自由移動を解除し、到達可能な最寄りのマップ端へ最短経路で直行する。壁をすり抜けず、端から外側へ1マス移動してマップから消える。出口が塞がれている場合は経路を再確認する。
- 出現・退出・空腹・収穫・食事は共通のゲーム時間で進み、一時停止と1倍・3倍の切替に従う。

## 木・野苺の自然発生とHP

- 木と野苺は、各種類につき1ゲーム分ごとに2〜3個ずつ、マップ上のランダムな空きマスへ発生する。建築物・予定地・既存の環境オブジェクト・地面アイテム・ポーンの現在位置と移動先に重ねない。
- 初期配置の木と野苺はHP1〜100％のランダムな成長度・ランダムな残寿命とする。開始後に新しく出現する木と野苺はHP1％から始まり、昼の成長時間を合計60ゲーム秒経過するとHP100％になる。岩の初期HPは100％。
- 成長はHPへ反映し、木・野苺の図形も徐々に大きくする。インフォメーションに現在のHPを表示する。
- 成長途中でも収穫できる。収穫量は「最大収穫量 × 収穫完了時のHP ÷ 100」の小数点以下切り捨て。HP50%の木は木材6個、野苺は苺2個。計算結果が1個未満なら0個。
- インフォメーションの収集量も現在のHPに応じて更新する。HP100%での最大量と収穫時間は、木が木材12個・4秒、野苺が苺5個・1秒。
- 収穫すると植物を取り除き、成長を停止する。新たな植物は毎分の自然発生で追加する。
- 自然発生・寿命消滅時に通行・停止可否の経路キャッシュを更新し、成長途中はHPと表示だけを更新する。


## 武器・装備・攻撃

- 武器をアイテムとして扱う。ライフル1丁をマップ中央の（16,17）マスに初期配置する。地面の図形・数量・選択・取得指定・運搬・保管・保管設定に対応する。
- ライフルの質量は5kg。人間の装備スロットは所持する資源の山とは別に管理し、装備中のライフルも最大20kgの所持制限に含める。
- ライフル装備中は資源を残り15kgまで持てる。木材15個、石材3個、苺75個、運搬用ライフル3丁が上限となる。建設用の取得・保管への運搬・予定地の整理で共通の上限を使う。
- 武器を装備していない人間は「素手」を自動装備する。素手は地面のアイテムとして生成せず、質量を加算しない。
- 生存するプレイヤーポーンを選択中、地面または保管エリアのライフルを右クリックすると「装備する」ウィンドウを表示する。自動・徴兵の両モードで利用でき、複数選択時は左の情報欄に表示中の人間が対象となる。
- 装備命令では現在の作業と食事を中断し、経路探索で武器へ向かい、到着してから1丁を装備する。武器のマスに停止できない場合は到達可能な隣接マスから取得する。他のポーンが先に取得した武器を複製しない。
- 交換時は以前のライフルを地面へ戻す。装備によって所持品が重量上限を超える場合は、超過分の資源だけを足元へ置く。元の徴兵・自動状態は保持する。
- 装備したライフルの図形はポーン本体より手前に重ねる。概要に装備武器を表示する。ライフルのインフォメーションには質量・射程・ダメージ・基礎命中率・攻撃間隔を表示する。
- 徴兵された生存プレイヤーポーンを選択し、他の生存ポーンを右クリックすると攻撃命令を出す。相手の勢力を問わず、人間と鹿を対象にできる。複数選択の場合は攻撃可能な選択ポーン全員に命令し、自分自身への攻撃は除外する。
- 攻撃命令の確定時、相手のマスへクロスした剣のアイコンを短時間表示する。
- 射程外では、射程に入る停止可能な地点のうち経路距離が最短の場所まで近づく。他のポーンと停止先を重ねず、壁を避ける。目標が移動した場合は必要に応じて再探索し、毎フレームの経路探索は行わない。
- 素手・ライフルの攻撃は毎ゲーム秒0.4回、すなわち2.5秒に1回。射程内の停止位置に到着してから2.5秒で初回の攻撃を行い、以後は同じ間隔で命中判定を繰り返す。攻撃と装備の命令中は、その命令を優先する。
- 手動の攻撃命令は相手の勢力にかかわらず、相手が死亡するまで同じ相手への攻撃を継続する。攻撃位置に到着した後は、射程外へ出ても追跡せず待機する。命中時は相手のHPを減らす。相手の死亡・マップ外への退出・自動への切替・新たな移動や装備や食事の命令で、その手動攻撃を解除する。

| 武器 | 攻撃範囲 | 1HITのダメージ | 基礎命中率 | 質量 |
| --- | --- | --- | --- | --- |
| 素手 | 隣接8マス（斜めを含む） | HP10% | 80% | 0kg |
| ライフル | 半径16マスの円に中心が内包されるマス（境界を含む） | HP40% | 50% | 5kg |

- 命中率は現状固定の基礎値を使い、後に相手の俊敏性に応じて変化させる。


## 鹿の逃走と自動攻撃・戦闘描画

- 鹿も人間と同じ満腹感・健康・HPを別々に持つ。初期健康・HPは100%。満腹感0では健康が毎ゲーム秒1%減り、健康0になるとHPが0.1ゲーム秒あたり1%減り、HP0で死亡する。鹿のインフォメーションに健康とHPをそれぞれ表示する。
- 鹿は攻撃を受けると、命中・不命中にかかわらず攻撃者から離れる方向へ8マスを基準に逃走する。経路探索で通行可能かつ停止可能なマスを選び、壁と他のポーンの停止先を避ける。
- 逃走先に環境オブジェクトや予約済みポーンがある場合は、その付近の到達可能なマスを選ぶ。マップ端などで逆方向へ進めない場合は、攻撃者へ近づかない側方の逃走先を選ぶ。地形上8マス進めない場合は到達可能な範囲まで逃げる。
- 逃走時は収穫・食事を中断して作業予約を解除する。情報の行動表示は「逃走中」。到着後は通常の自由行動・食事へ戻り、退出フラグがあればマップ端への退出を再開する。逃走中も空腹・健康・HPの時間経過は止めない。
- 敵対関係は「プレイヤー」と「敵１」の間で相互に成立する。「野生」はどちらとも敵対せず、自動攻撃の対象に含めない。
- 明示的な攻撃・装備・今すぐ運搬の命令がない人間は、徴兵・自動の両モードで、自分の武器の射程内に生存する敵対ポーンがいれば最寄りの相手を自動攻撃する。敵１側の人間にも同じ判定を使う。
- 自動攻撃は射程内の敵対相手だけを対象とし、範囲外の相手を追跡しない。手動の攻撃命令は自動の対象選択より優先し、途中で相手の勢力が変わっても同じ相手への攻撃を継続する。
- 自動の敵探索は0.25ゲーム秒間隔で行い、射程内の相手を探すだけなので経路探索は行わない。手動攻撃の追跡と鹿の逃走は既存の地形経路キャッシュを利用する。
- ライフル発砲時は銃口に発砲炎を描画する。命中なら射手から相手の位置へ弾道を、不命中なら相手の近辺（0.6～1.5マスのずれ）へ弾道を表示する。
- 命中判定とHPダメージは発砲した瞬間に計算する。弾道は視覚表現として表示し、表示終了までダメージを遅延させない。
- 命中でダメージを受けた位置から、赤い粉末状の粒子を10個散らす。素手の命中にも同じ被弾表現を使う。
- 発砲炎は0.12ゲーム秒、弾道は0.18ゲーム秒、赤い粒子は約0.45～0.65ゲーム秒で消える。カメラ・ズームに追従し、一時停止・倍速もゲーム時間に従う。消えた図形は破棄し、蓄積させない。
- 生存する選択中の徴兵された人間について、射程が1マスより長い武器の攻撃範囲を白い枠で表示する。自動モード、射程1マスの近接攻撃・素手では表示しない。ライフルは半径16マスの円に含まれるマスの外周とし、マップ外は切り取る。
- 複数選択時はそれぞれの射程枠を表示し、選択解除・死亡時に消す。枠はマス位置と装備が変わったときだけ再生成する。


## 今すぐ運搬と装備武器の放置

- 自動モードの生存プレイヤーポーンを選択し、地面のアイテムを右クリックすると「今すぐ運搬」を選択できる。武器では「装備する」、苺では「今すぐ食べる」と並べて表示する。複数選択時は左の情報欄に表示しているポーンが担当する。
- 「無視」のアイテムにも命令でき、取得・無視の設定は変更しない。徴兵モードではこの運搬操作を表示しない。
- 命令したポーンは現在の作業を中断し、そのアイテムを受け入れ可能な最寄りの保管箱・保管エリアへ運ぶ。既に所持品がある場合は先にその所持品を保管する。
- 指定したアイテムの山を重量上限内で繰り返し運び、山がなくなるか保管先に空きがなくなれば終了する。装備武器の質量も運搬上限へ反映する。
- 命令中は通常の作業優先順位と自動攻撃より優先する。アイテムの担当を往復中も予約し、他のポーンとの重複取得を防ぐ。終了後は元の自動行動へ戻る。
- 到達可能で受け入れ可能な保管場所がない場合、または別のポーンが予約中の場合は「今すぐ運搬」を無効化する。中断しても所持品を失わず、予約を解除する。
- 「地面に置く」ボタンは装備武器だけを持っている場合も有効となる。停止可能なマスまで進み、資源の所持品と装備中のライフルを一緒に地面へ戻す。武器の重ね描画を消し、装備を素手へ戻す。素手そのものは地面に生成しない。


## 解体所・解体作業・肉

- 作業所タブに「解体所（木材）」を追加する。建設費は木材30個、建設時間は3ゲーム秒。
- 解体所は中央のマスを基準に1×3マスを占有する。配置中にRキーで縦・横を切り替え、3マスのプレビューを表示する。完成後は3マス全てを通行・停止不可とする。
- 3マスがマップ外に出る、または他の建築物・予定地と重なる場合は配置できない。各マスの環境オブジェクト・地面アイテムを先に片付ける。端のマスを右クリックしても建設予定をまとめて削除できる。
- 完成した解体所のいずれかのマスをクリックすると、左下にインフォメーションを表示する。右上の「作業」ボタンで作業一覧ウィンドウを開く。
- 作業は「解体」。解体ボタンを押すと1回予約し、＋で1増加、−で1減少する。回数は0～99。0は赤字で表示する。
- 「アイテム［数値］まで繰り返す」では肉の現在数が指定数以上になるまで作業する。判定は地面・保管場所・生存ポーンの所持する肉の合計。肉は10個単位で生成するため、目標数を超える場合がある。
- 「無限」では解体できる死体がある限り続ける。回数指定・アイテム数指定・無限の3モードは排他的に切り替える。
- 優先順位一覧に「解体」を追加し、初期値は3、クリック・右クリック・色分けは既存の優先順位と共通とする。死体の搬入は「運搬」、加工は「解体」を使う。
- 生存する自動ポーンが、取得指定された人間・鹿の死体を1体ずつ搬入する。死体の所在と解体所を予約し、同じ死体の重複取得・同じ設備での同時加工を防ぐ。
- 搬入した死体は1×3マスの中央に置き、中央マスに隣接する停止可能なマスから作業する。ポーンは設備の占有マス内には立たない。
- 1体を5ゲーム秒で解体する。徴兵・食事・他の仕事等で中断した場合も設備に死体と加工進捗を保存し、再開時は途中から続ける。予約を0に戻した場合も途中の死体は残る。
- 解体完了で死体を除去し、作業ポーンの足元へ肉10個を地面アイテムとして生成する。肉は取得指定となる。死体に残っていた資源や装備武器も地面へ戻し、消失させない。
- 肉は1個1kgの食料。苺と共通の自動・手動食事を使い、1個で満腹感20%回復する。食事時間は個数にかかわらず1秒で、満腹になるまで必要な個数を食べる。保管設定と保管アイテム集計にも肉を追加する。

## 死体の取得・保管と重いアイテム

- 人間・鹿の死体にも「無視・取得」を持たせ、初期状態は無視。死体を選択すると右下の取得ボタンで切り替えられる。Shift・ドラッグで複数の死体を選択した場合もまとめて切り替える。
- 取得指定した地面の死体には目印を表示する。無視の死体は自動で運ばず、解体対象にも含めない。
- 作業予約のある解体所に搬入できる場合はそこへ運び、それ以外では受け入れ可能な保管箱・保管エリアへ運ぶ。解体作業には保管済みの死体も取り出して利用する。
- 人間の死体は50kg、鹿の死体は120kg。死体は1体ずつ運ぶ。通常の20kg上限を超える重いアイテムも、最低1個ずつ運べる共通ルールとする。装備武器の重量で通常の積載量は減るが、最低1個は維持する。
- 保管箱・保管エリアの受け入れ設定に「人間の死体」「鹿の死体」を追加する。保管中の死体は個別のポーン図形を隠し、保管アイテム欄へ種類ごとの個数を表示する。保管エリアでは通常の1種類・100個の制限を使う。
- 運搬中の死体は運搬者に追従して表示する。中断した場合は、到達可能な別の空きマスへ置き直す。保管箱を破壊した場合も保管中の死体を地面へ戻す。
- 解体済みの人間はマップの図形と一覧から除去する。死亡前の自発行動や操作を再開しない。

- 死体も自動モードのポーンを選択して右クリックすると「今すぐ運搬」を指定できる。無視設定を維持したまま、予約のある解体所または受け入れ可能な保管場所へ運ぶ。保管済みの死体は、無視設定でも解体予約に使用できる。

## 植物の寿命と武器の更新

- 木・野苺は出現から180ゲーム秒で消滅する。初期配置分は180秒以内のランダムな残寿命とする。夜も寿命を消費する。寿命による消滅では資源を落とさない。岩には寿命を適用しない。一時停止中は寿命も停止し、速度変更に追従する。
- ライフルの命中率は50％、素手は80％。ダメージ・射程・2.5秒の攻撃間隔は従来通り。
- ライフルは発砲時のみ対象方向を向き、発砲炎の表示時間0.12秒が終わると回転0度の正位置に戻る。
- 地面に置いたライフル・ナイフは、装備時と共通の武器の形で表示する。鹿の死体は鹿の形のまま横倒しで表示し、保管エリアでも四角形に置き換えない。
- ナイフを初期マップ中央に1個配置する。質量2kg、命中率90％、ダメージ40％/HIT、斜めを含む隣接1マスに攻撃可能。攻撃間隔は1ゲーム秒。攻撃時に0.25秒の振るモーションを表示し、終了後は回転0度に戻す。射程の白枠は表示しない。
- ナイフの装備指示・運搬・保管・所持重量・地面に置く・解体時の装備返却は既存武器と共通。武器交換では以前の武器を地面へ戻す。

- 保管エリアに表示しているアイテムを左クリックで選択し、「？」から質量や武器性能を確認できる。数量が0になったりエリアが撤去された場合は選択を解除する。Shift・同種の付近のダブルクリック選択にも対応する。既に保管済みのアイテムだけを選択した場合は取得ボタンを表示しない。

- 解体中は解体所の中央マスの下に進捗バーを表示する。0％・100％では非表示とし、中断時も保存した進捗を表示する。完成した肉は取得状態で生成し、運搬の対象となる。

- 木・岩の収集で生成された木材・石材も、苺・肉と同様に初期状態を取得とする。既存の地面の山に合流した場合も、その山を取得状態に切り替える。

## 扉・狩猟・食料の栄養

- 建設→建物に「扉（木材）」を追加する。1マス、木材15個、建設時間1ゲーム秒。建設予定・素材搬入・進捗保存・破壊は既存建築と共通。素材は木材固定。
- 完成した扉はプレイヤー勢力が通行・停止可能。扉のマスに立って扉と重なることができる。敵１・野生は完全に閉じた扉（開閉度0％）には移動・通過不可だが、開閉度が0％を超えている間は通行・停止可能。経路探索・移動・鹿の収集/逃走/退出に同じ勢力別ルールを適用する。予定段階は従来通り通行できる。
- プレイヤーの接近・通過時は扉の左右の板が0.2ゲーム秒で開く。通過後0.2秒待ってから0.2秒で閉じる。開いた扉上にいずれかの勢力の生存ポーンがいる間は開いた状態を保つ。一時停止・倍速に追従する。
- 優先順位に「狩猟」を追加する。初期値3、数値の色・左右クリックの変更方法は共通。優先順位同値は収集→運搬→建設→解体→狩猟→自由。
- 生存する鹿を選択すると右下に「🏹 狩猟・無視」の切替ボタンを表示する。初期は無視。複数選択時もまとめて設定できる。
- 自動のプレイヤーポーンは、狩猟が選ばれた時点で最も距離が近い到達可能な狩猟対象の鹿を選び、射程に入る地点まで経路探索して追いかけ、倒すまで武器で攻撃する。途中で別の鹿が近づいても対象を変えない。
- 狩猟チェック解除・徴兵・優先順位の変更・別の明示命令などで狩猟を中断できる。仕留めた鹿の死体は取得状態となり、狩猟チェックを解除する。行動欄には「狩猟中」と表示する。
- 食料に栄養を追加する。肉20、苺10。地面・保管エリアの選択情報に栄養を表示する。食料以外には表示しない。
- 満腹感の回復は栄養と同じ百分率とし、肉1個で20％、苺1個で10％回復する。人間の自動/手動食事と鹿の食事で共通。満腹まで必要な個数を食べるが、食事時間は1秒固定、満腹感の上限は100％。

## 射線・バリケードの遮蔽・徴兵中の待機

- ライフルの射線は、射手と相手のマス中央を結ぶ線で判定する。完成した壁・扉が射線上にある場合は発砲・命中判定・ダメージを行わない。予定地は射線を遮らない。対角の角を挟む壁も射線を遮る。
- 完成したバリケードは射線を通すが、ライフルの命中率から40ポイントを減算する（50％→10％、下限0％）。複数のバリケードを横切っても減算は一度。素手・ナイフには適用しない。
- 初回の攻撃指示が射程外・壁越しの場合は、射程内かつ射線の通る最も近い到達可能な射撃地点へ移動する。
- 徴兵中の手動攻撃は、一度攻撃位置に到着した後は相手が射程外・壁の向こうへ移動しても追跡せずその場に留まる。対象への指示を保持し、射程内で射線が通る位置に戻れば攻撃を再開する。対象死亡・退出・別指示などの解除条件は従来通り。
- 自動モードの狩猟はこの待機制限を適用せず、引き続き対象を追跡して仕留める。

- 扉は完成後、開閉アニメーションの状態にかかわらず銃弾を遮る。プレイヤーが扉のマスに立ち止まっている間は開いた表示を保つが、射線遮蔽の判定は維持する。

- 徴兵中のポーンは、自動で所持・地面・保管場所の食料を食べたり取りに行ったりしない。徴兵への切り替え時は進行中の自動食事を中断する。満腹感・健康・HPの減少は続く。「今すぐ食べる」の明示命令は徴兵中も実行できる。

## 初期植物・指示ボタン・鹿の出現間隔の更新

- ゲーム開始時に配置する木・野苺は、HP1〜100％のランダムな成長度と、0秒を超え180秒以下のランダムな残寿命を個体ごとに独立して設定する。岩はHP100％・寿命なし。開始後に出現する植物はHP1％・寿命180ゲーム秒で出現する。収集量は成長度に比例する。
- 鹿の狩猟指定はチェックボックスからボタンへ変更する。「🏹 狩猟」「無視」をクリックで切り替える。初期は無視。
- 地面のアイテムと死体の取得指定ボタンは「🧺 収集」「無視」で切り替える。内部の取得・運搬指定の挙動は維持する。
- 鹿の出現・退出指定は従来通り各2〜3匹／約1分とする。各波の間隔は50〜70ゲーム秒。

## 狼・死体の捕食

- 野生勢力の狼を追加する。操作不可で、人間・鹿と同じ満腹感・健康・HP、自由移動・経路探索・停止先の予約を持つ。満腹感・健康・HPの初期値は100％。狼を選択して「？」から状態を確認できる。
- 狼は初期出現波を含め、マップ端に1〜2匹ずつ出現する。次の出現・退出指定の間隔はそれぞれ独立した110〜130ゲーム秒（約2分）。端の空きマスに生成し、退出対象は到達可能な最寄りの端から外へ移動する。完全に閉じた扉は通過できない。少しでも開いている扉は通過できる。
- 狼は満腹感20％以下で、到達可能な鹿を食料として探す。生存する相手には近接攻撃し、倒したら死体を捕食する。鹿の死体も利用可能。鹿が利用できなければプレイヤー勢力の人間を対象とする。敵１は捕食対象にしない。
- 狼の近接攻撃は現状の素手と同じ、隣接8マス・命中80％・ダメージ10％・間隔2.5秒。狙った相手を追跡する。攻撃された鹿は従来通り8マス逃げる。野生とプレイヤー全体の敵対関係は変更せず、狼の空腹による捕食を個別の行動として扱う。
- 死体の栄養は100。狼・人間とも、隣接する停止可能なマスから1ゲーム秒で1体を捕食し、満腹感を100ポイント回復する（上限100％）。捕食完了で死体を除去し、残っている所持品・装備は地面へ戻す。肉アイテムは生成しない。
- 自動モードの人間は、通常の所持食料・地面の食料・保管食料が利用できない場合、到達可能な死体を直接捕食する。無視指定の死体も対象になる。徴兵中は自動捕食しない。
- 生存プレイヤーポーンを選択して死体を右クリックすると「捕食する」を表示する。徴兵・自動の両モードで明示的な捕食指示を実行できる。自動モードでは「今すぐ運搬」も引き続き表示する。
- 保管済みの死体も直接食べることができ、保管数と死体の実体を一緒に減らす。運搬・解体・他の捕食者が予約中の死体は捕食できない。中断時は死体を残し、捕食予約を解除する。
- 狼の死体は狼の形を維持し、質量の初期設定は50kg。取得・保管・解体は既存の死体と共通。保管設定に狼の死体を追加する。

## 建造物の選択・HP・攻撃

- 完成した壁・扉・バリケード・保管箱・保管エリア・解体所は左クリックで選択できる。Shiftを押しながらクリックすると複数選択する。解体所は占有するどのマスからも同じ設備を選択する。保管エリア上のアイテムがある場合は従来通りアイテムを優先して選択する。
- 選択した建造物は黄色い枠で示し、左下の情報欄に種類・素材・HPを表示する。HPの初期値は100％。解体所の情報欄には既存の作業ボタンと進捗も表示する。
- 徴兵した人間は完成した建造物を右クリックして攻撃できる。武器の射程・命中率・ダメージ・射線判定を使う。狙った壁・扉そのものは射線の到達先として扱うが、途中の別の壁・扉は銃弾を遮る。
- 動物は建造物を攻撃できない。狼の捕食対象にも含めない。
- 建造物への命中は赤い粉末の代わりに黄色い星を表示する。人間・動物への命中は赤い粉末のまま。
- HP0％で建造物を撤去し、既存の破壊と同じく建設素材の半分（端数切り捨て）を地面へ返す。保管物・保管死体・解体中の死体を失わず地面へ戻し、設備に関連する作業と選択を解除する。

- 初期マップ中央（15,17）に携帯食料40個の山を配置する。1個1kg・栄養30、1個で満腹感30ポイント回復する。初期は収集状態。運搬・保管・概要・栄養情報・自動食事・右クリックの「今すぐ食べる」は他の食料と共通。


## 捕食・死亡・攻撃表示の更新

- 狼の捕食対象は追跡開始時に到達可能性を判定し、追跡中に壁や扉の閉鎖で経路が塞がれた場合も対象を解除し、到達可能な別の対象を選ぶ。経路の再判定は0.25ゲーム秒間隔とし、既存の経路キャッシュを利用する。壁の角を挟んだ近接捕食はできない。
- 人間・狼の死体捕食も0.25ゲーム秒間隔で到達可能性を確認する。到達不能なら作業・予約を解除し、自動行動では別の対象を選び直す。
- 狼は無視状態の死体も食べる。鹿を優先し、利用できない場合は人間（プレイヤーを含む）・狼の利用可能な死体、次いで生存プレイヤーポーンを候補にする。運搬・解体・他者の捕食予約中の死体は除外する。
- 人間・動物が死亡すると装備武器を周囲の通行・配置可能なマスへ1個落とし、装備を素手へ戻す。周囲に空きがない場合は死亡マスへ落とす。死亡処理が繰り返されても重複生成しない。その他の所持品は既存の死体処理を維持する。
- 全ポーン（人間・動物）は攻撃ごとに0.25ゲーム秒、体が左右に揺れる。命中・外れ、近接・射撃とも適用し、武器の既存の振り・発砲モーションと併用する。死亡時の横倒しを優先する。
- 上部ポーンボタンは3人時と同じ正方形サイズを維持し、表示人数が1〜2人に減っても拡大しない。ボタン群は画面上中央に配置する。
- 近接攻撃（素手・ナイフ・動物）では相手の方向に半月状の明るい攻撃エフェクトを0.25ゲーム秒表示し、フェードアウトする。命中・外れとも表示する。ライフルは既存の発砲炎・弾道を使う。


## 逃走・反撃と動物の食事

- 攻撃対象となった生存プレイヤーポーンは、徴兵・自動を問わず現在の作業・攻撃を中断し、鹿と共通の経路探索で攻撃者から反対方向へ8マスを目安に逃げる。壁・端・他者の停止予約を避け、到達可能な逃走先を選ぶ。移動終了後は元のモードで行動を再開する。所持品は維持し、建設・解体・調理の設備側の途中進捗を保存する。新しい移動先を指示した場合は逃走指示を置き換えられる。
- 攻撃対象となったプレイヤーポーンの上部ボタンの枠は赤くする。最後の攻撃から3ゲーム秒間表示し、連続攻撃では延長する。死亡後は赤枠を解除する。命中・外れとも逃走・赤枠・狼の反撃を適用する。
- 攻撃対象となった生存狼は、満腹感によらず攻撃ごとに50％で反撃、50％で鹿と共通の8マス逃走を選ぶ。反撃を選んだ場合は攻撃者を近接攻撃の対象にする。射程まで到達可能なら追跡し、相手の死亡・退出・到達不能で解除する。反撃中は食事・通常の捕食対象探索・自由より反撃を優先する。動物は建造物を攻撃しない。
- 狼は満腹感20％以下で、到達可能な肉・携帯食料を食べられる。鹿は到達可能な苺・携帯食料を食べられる。地面の無視指定アイテム・保管済みアイテムも動物の食料になる。各種の栄養と1秒の食事時間を使い、満腹になるまで食べる。鹿は肉を、狼は苺を食べない。
- 狼は利用できる通常食料を優先し、なければ従来の鹿・死体・プレイヤーへの捕食を行う。鹿は利用できるアイテムがなければ従来通り野苺を収穫して食べる。逃走・退出中は新たな食料を探して寄り道しない。

## 調理器

- 建設→作業所に「調理器（木材）」を追加する。初期の占有は3×1マス、Rで1×3マスに回転可能。木材30個・建設4ゲーム秒、HP100％。完成設備の3マスは通行不可で、中央の隣接マスから作業する。
- 設備選択→「作業」で、解体所と共通の作業予約ウィンドウを開く。「調理」・−・＋（0〜99回、0は赤字）、携帯食料の目標個数まで繰り返す、無限を選択できる。解体所の予約は独立して維持する。
- 肉（栄養20）・苺（栄養10）の合計栄養100を材料とし、1回5ゲーム秒で携帯食料4個（既存の質量1kg・栄養30）を作る。肉5個、苺10個、肉3個＋苺4個など、単独・混合の材料が使える。整数個単位で必要量だけ搬入し、材料不足では加工を開始しない。
- 材料は収集指定の地面アイテム、保管場所のアイテム、ポーンの所持材料から搬入する。「運搬」の仕事で搬入し、新設の「調理」の仕事で加工する。調理の初期優先順位は全員3で、既存の1〜4循環・色・右クリック逆順を適用する。
- 搬入は既存の20kg上限と装備重量を適用する。1設備で同時に搬入・加工を行うのは1人だけ。材料と途中進捗を設備に保存し、徴兵・食事・攻撃・優先順位変更で中断されても再開できる。途中の進捗バーは設備の下へ表示し、0％・100％で消す。
- 完成品は作業ポーンの位置の地面へ「収集」状態で配置する。目標数の判定では地面・保管・生存ポーン所持の携帯食料を合計する。調理器が破壊された場合は、建設資源半分と搬入済みの未消費材料を地面に戻す。

## 日時・昼夜・光と影

- 1ゲーム秒でゲーム内30分、48ゲーム秒で1日が経過する。初期日時は暫定で1年1月1日08:00。年月日・時のみ（分・秒なし）を画面の右中央に小さく表示し、日付は暦に沿って繰り上げる。一時停止・1倍・3倍に連動する。
- マップ全体にGPUシェーダーを適用し、昼（07:00〜16:00）は元の色、夕方（16:00〜18:00）は赤み、夜（20:00〜05:00）は濃紺の暗い色にする。05:00〜07:00と18:00〜20:00は滑らかに色調を補間する。HTMLの操作UI・日時は暗くしない。
- 完成した壁・扉の影を背景のすぐ上、全オブジェクトの下へ描画する。06:00〜18:00に朝は左、昼は中央の短い影、夕方は右へ伸ばし、夜は消す。時刻に応じて方向・長さ・濃さを変え、建設・破壊を反映する。影の再描画はゲーム内3分間隔と建造物変更時に限定する。
- 建設→建物に「たいまつ（木材）」を追加する。1マス、木材1個・建設1ゲーム秒、HP100％。完成したたいまつはGPUシェーダーで半径約4マスへ暖色の光を発し、距離で弱まる。予定地は光らない。完成した壁・壁の角は光を遮り、予定の壁は遮らない。
- 光は昼夜の色調と同じ1回のシェーダーで合成する。マップ上の光量・遮蔽は建造物変更時にキャッシュし、カメラ移動やズームでは遮蔽を再計算しない。複数たいまつでは光量を最大値で合成し、重複による過剰な明るさを避ける。

- 夜の色調は濃紺を維持しつつ、RGBの明るさ係数を0.45・0.50・0.75とし、環境オブジェクト・アイテム・壁・ポーンの視認性を改善する。夕方・朝との補間、たいまつの照明は維持する。

- 昼夜・たいまつ用シェーダーの描画範囲は、画面全体をマップのローカル座標に逆変換して設定する。カメラ移動・ズーム・画面サイズ変更時に更新し、スマートフォンの縦画面で右側、横画面で下側が切れないようにする。

- プレイヤーポーンは、連続する1回の徴兵につき、ゲーム内12〜18時間（24〜36ゲーム秒）の一様乱数で自動解除時刻を1回だけ抽選する。12時間より前には自動解除せず、18時間までには全員自動モードへ戻る。初期状態の徴兵も対象。ポーンごとに計測し、手動で解除・再徴兵した場合は計測をリセットする。一時停止・倍速に連動し、死亡ポーンは対象外。自動解除時は徴兵中の移動・攻撃・装備取得指示を解除し、通常の自動行動を再開する。

- 植物（木・野苺）の成長は06:00以上18:00未満だけ進み、18:00〜翌06:00は停止する。寿命・出現の周期は昼夜とも進む。新しい植物は昼の成長時間を合計60ゲーム秒経過するとHP1％から100％になる。初期の成長度と残寿命は独立して抽選する。
- 狼の情報ウィンドウには「反撃確率 50%」を表示する。攻撃ごとに再判定し、逃走中は食事・捕食・反撃を中断して逃走先へ移動する。反撃を引いた場合は逃走を解除し、以前と同じ近接攻撃で攻撃者を追跡する。反撃・逃走を選んでも野生勢力全体の敵対関係は変えない。


## 覚醒度・就寝・ベッド

- 覚醒度は満腹感と同じく1ゲーム秒あたり1％減少する。一時停止・1倍・3倍に連動する。覚醒度0％になると、通常の仕事・食事・移動・戦闘を中断し、その場で横倒しになって眠る。移動途中の場合は次の停止可能なマスの中央に到達して眠り、他のポーンや停止禁止のマスに重ならない。
- 地面での睡眠はゲーム内8時間で100％（16ゲーム秒で100％）、ベッドでの睡眠はゲーム内6時間で100％（12ゲーム秒で100％）の速度で覚醒度を回復する。100％で目覚める。睡眠中も満腹感・健康・HPの時間変化は続く。睡眠中は移動・攻撃・装備・食事・運搬の指示によって起こさない。
- 建設→家具→「ベッド（木材）」を追加する。縦1×2マス、Rキーで横2×1マスへ回転する。必要素材は木材5個、建設時間は3ゲーム秒。HPは100％。予定地・搬入・建設進捗・選択・攻撃・破壊は既存の建造物と共通。作業予約や「作業」ボタンは付けず、睡眠専用とする。
- 完成したベッドは通常の通行・停止・移動先指定を禁止する。自動モードで覚醒度が20％未満のプレイヤーポーンは、経路探索で最も早く到達できる空きベッドに向かい、隣接マスからベッド上へ移って横倒しで眠る。1つのベッドは移動中の予約も含めて1人だけが利用できる。起床後は空いている隣接マスへ降りて通常行動に戻る。
- 徴兵中は低覚醒度でもベッドへ向かわない。ただし0％での地面への寝落ちは適用する。ベッドへ移動中に徴兵した場合は予約を解除して移動を止める。睡眠中に徴兵を切り替えても100％まで眠り続ける。
- ベッドが破壊された場合、就寝中のポーンは地面での睡眠へ切り替わり、覚醒度を保持する。死亡時はベッドの予約を解除する。野生の鹿・狼も覚醒度0％では地面で眠るが、ベッドは使わない。
- ポーン情報の概要に「就寝へ移動中」「就寝中」「起床中」を表示する。狭い画面でも家具追加後の全建設タブを利用できるよう、下位タブは横スクロールできる。

- 狼・鹿のインフォメーションにも「覚醒度」のゲージ・数値を表示する。人間と同一のゲージ描画コンポーネントと `Sleeping` を使い、初期100％・毎ゲーム秒1％減少・0％で地面に就寝・ゲーム内8時間で100％回復・100％で起床を共通化する。就寝中は横倒し・行動「就寝中」となり、採食・捕食・自由移動を休止する。満腹感・健康・HPは変化し続け、野生動物はベッドを利用しない。
